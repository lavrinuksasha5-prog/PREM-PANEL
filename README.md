# TWKS Panel

Веб-панель менеджера аккаунтов. Открывается в браузере по ссылке,
кнопки реальные: загрузил архив → жмёшь «Открыть Web» → поднимается окно
в Окто → закрыл окно → слот свободен → следующий.

---

## Шаг 1. Залить на GitHub

```
git init
git add .
git commit -m "twks panel"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/twks.git
git push -u origin main
```

Репозиторий делай **приватным**. `.env`, архивы и сессии в гит не попадают —
они в `.gitignore`.

---

## Шаг 2. Railway

1. New Project → Deploy from GitHub repo → выбираешь `twks`.
2. Variables → добавь:

```
TWKS_ADMIN_PASSWORD = свой пароль
TWKS_SECRET_KEY     = любая длинная случайная строка
TWKS_AGENT_TOKEN    = любой секрет для агента
TWKS_MAX_SLOTS      = 2
```

3. Settings → Networking → Generate Domain.

Всё, панель живёт по ссылке вида `https://twks-production.up.railway.app`.
Открывается с телефона, с любого компа.

`DATABASE_URL` Railway подставит сам, если добавишь Postgres.
Без Postgres панель работает на SQLite (данные живут, пока живёт контейнер).

## Шаг 3. Агент на ПК

Из облака до Окто не достучаться — он слушает только localhost твоего компа.
Поэтому на ПК висит маленький агент, он и есть мост. Он сам стучится в панель,
никаких пробросов портов.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

set TWKS_PANEL_URL=https://твой-домен.up.railway.app
set TWKS_AGENT_TOKEN=тот_же_секрет_что_в_railway

python agent\agent.py
```

Или просто двойной клик по `start_agent.bat` (там же можно вписать адрес).

Пока агент не запущен, панель пишет «агент офлайн» и кнопку не даёт нажать.

**Мок-режим.** По умолчанию окна эмулируются таймером 25 секунд — Окто не нужен.
Чтобы включить настоящий Окто, в переменных агента:

```
TWKS_OCTO_MOCK=false
TWKS_OCTO_TOKEN=токен_из_настроек_окто
```

## Локально, без облака

`start_panel.bat` → http://127.0.0.1:8000, пароль из `.env`.

## Что уже работает

- Загрузка ZIP, поиск tdata на любой глубине.
- Прокси привязаны к партии, проверка по кнопке.
- Жёсткий лимит окон: 2 занято → третья кнопка мертва на клиенте и на сервере.
- «Завершить» освобождает слот мгновенно.
- Агент видит закрытие окна крестиком и освобождает слот сам.
- Карточка устройства на аккаунт (Xiaomi, Samsung, Pixel, iPhone).
- Сессия шифруется и скачивается одной кнопкой.
